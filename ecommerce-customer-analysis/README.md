# E-commerce Customer Analysis

Two Python projects analysing an e-commerce dataset made of transactions,
customers and web sessions.

## Projects

### 01. EDA and Customer Segmentation
- Merged three tables and answered business questions with pandas
- Visualised purchase value by year and product category
- Built a rule-based segmentation: Discount Hunter, Fast High-Spender,
  Hesitant Browser, Regular Customer

### 02. Statistical Testing
- Welch t-tests, chi-square tests and Pearson correlations
- Compared spending and conversion across country, gender, device,
  discount usage and acquisition channel
- Discussed statistical significance vs. practical importance

## Key takeaways
- Spending is similar across countries, genders and acquisition channels
- Pages viewed has a weak but significant link with conversion
- A significant p-value does not always mean a result matters for the business

## Tools
Python, pandas, matplotlib, scipy, Jupyter

## Data
The notebooks use datasets (transactions, customers, web sessions) provided
for a course exercise. The raw data files are not included in this repository
and cannot be shared. The notebooks show the code and the aggregated results.
